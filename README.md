# FitLyfe

FitLyfe is a health-tracking Android application designed to help users monitor their daily health metrics, track nutrition consumption, and stay accountable to their wellness goals.

## Project Overview
FitLyfe serves as a personal fitness companion, enabling users to log activities, analyze health data, and receive structured goal reminders. Built entirely within Android Studio, the application leverages Firebase for secure, real-time backend data storage and user authentication.

## Key Features
* **Health Metrics Analysis:** Track and view progress on key fitness and health data points over time.
* **Consumption Reports:** Review nutritional and dietary intake summaries to maintain balanced habits.
* **Goal Reminders:** Stay motivated with automated notifications and reminders aligned with personal fitness targets.
* **Cloud Integration:** Uses Firebase database connections to securely sync user data and account information in real time.

## Tech Stack
* **Platform:** Android (via Android Studio)
* **Backend / Database:** Firebase Database
